# chatdpt-react-agent

A ReAct agent built with LangChain, LangGraph, Groq, and Tavily Search.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment variables:
   Copy `.env.example` to `.env` and fill in your API keys:
   ```bash
   cp .env.example .env
   ```

3. Run the agent:
   ```bash
   node agent.js
   ```
